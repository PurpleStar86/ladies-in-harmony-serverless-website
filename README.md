# Ladies in Harmony – Serverless Website

A responsive ministry website built for a real client using a serverless AWS architecture.

This project provides information about the Ladies in Harmony prayer group, allows visitors to submit prayer requests, displays upcoming events, and shares a daily Bible verse while keeping operational costs low through AWS serverless services.

---

## Project Overview

Ladies in Harmony is a faith-based prayer ministry website designed to provide:

- Prayer request submissions
- Daily Bible verses
- Upcoming ministry events
- Contact information
- Responsive mobile-friendly design
- Memorial tribute section

Prayer requests are securely processed through a serverless backend and stored in Amazon DynamoDB while email notifications are delivered using Amazon SES.

---

## AWS Architecture

Frontend

- Amazon S3 (Static Website Hosting)
- Amazon CloudFront (Production deployment)

Backend

- Amazon API Gateway
- AWS Lambda (Python)
- Amazon DynamoDB
- Amazon Simple Email Service (SES)
- Amazon CloudWatch
